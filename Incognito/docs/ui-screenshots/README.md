# UI Screenshot Manifest

This folder contains screenshot slots for all routed UI screens.

## How to use

1. Run backend and frontend locally.
2. Navigate to each screen listed below.
3. Capture a 16:9 screenshot (recommended around 1600x900).
4. Replace the corresponding placeholder file while keeping the same file name and path.
